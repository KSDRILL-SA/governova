# Govtech — `D-GOVTECH`

**Status:** Ratified — 5 standards (`D-GOVTECH.1`–`D-GOVTECH.5`)
**Regulatory basis:** POPIA · GDPR-adjacent · public-sector procurement
**Seeded from:** Maphophe Community System

The domain constitution is [`D-GOVTECH-domain-constitution.md`](./D-GOVTECH-domain-constitution.md).

| ID | Standard |
|----|----------|
| `D-GOVTECH.1` | Citizen data residency is declared and enforced |
| `D-GOVTECH.2` | A public service works on the device and connection citizens have |
| `D-GOVTECH.3` | Citizens can see, correct, and export the record held about them |
| `D-GOVTECH.4` | Public systems remain operable without their vendor |
| `D-GOVTECH.5` | Decisions affecting a citizen are attributable and explainable |

Applies to any system delivering a public service or holding citizen records — not only
to the reference system it was seeded from. See `constitution/domains/README.md` for the
full registry and `framework/format-specification.md` for the format.
